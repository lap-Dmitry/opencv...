# План действий для работы
> 1. Удалить opencv и contrib (Для профилактики) - pip uninstall -y opencv-python opencv-contrib-python
> 2. Установить contrib - pip install opencv-contrib-python
> 3. Скачать файл можно в google colab с помощью команды, а затем загрузить в проект - !wget https://raw.githubusercontent.com/opencv/opencv/master/data/haarcascades/haarcascade_frontalface_default.xml
> 4. Попробовать запустить
